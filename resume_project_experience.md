Project: Digital Wellbeing in Asia — NLP and Predictive Analytics for Public Sentiment

Built a reproducible data science pipeline to analyze multilingual social media discussions on digital wellbeing in Asia, using a large-scale Exorde dataset and DuckDB for efficient filtering and storage. Compared traditional TF-IDF pipelines with multilingual sentence embeddings and evaluated Elastic Net, XGBoost, and Neural Network classifiers for sentiment prediction. The project delivered a policy-relevant analysis of public attitudes around screen time, device dependency, and online behaviour, with clear findings on model performance, cultural nuance, and implementation considerations.

- Applied end-to-end NLP and machine learning workflow: data cleaning, feature engineering, model comparison, and evaluation
- Designed a scalable analytics pipeline using DuckDB for large dataset handling and SQL-based filtering
- Assessed multilingual and culturally nuanced text using modern embedding-based methods and benchmarked model performance
- Communicated results through a structured report and reproducible R/Markdown workflow suitable for stakeholder use
